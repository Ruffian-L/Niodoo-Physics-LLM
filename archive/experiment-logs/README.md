# Archived experiment logs

Raw output logs from the exploratory tuning and stress-test runs that led to the
parameters documented in [`../../docs/TUNING.md`](../../docs/TUNING.md) and the
benchmark results in the main [`README`](../../README.md).

These are kept for transparency and provenance, not as polished results. They are
verbatim run logs, so they include model output that is sometimes garbled or wrong —
that is expected for high-force settings and is part of what the runs were measuring.

The primary, load-bearing results live in [`../../artifacts/`](../../artifacts/) —
the multi-seed, blind-judged PARB run and its telemetry.

File names were normalized in July 2026 for a neutral, professional tone; the file
contents are unchanged from when they were generated (December 2025).
